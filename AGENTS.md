# Proyecto
Este es el archivo principal del proyecto. Contendrá toda la información sobre el propósito del proyecto y sus reglas.

## Reglas del Proyecto
- El proyecto debe utilizar Node.js para su inicialización y gestión de dependencias.
- Las tareas de desarrollo deben incluir un script `watch` para compilar los estilos en tiempo real.

## Información del Proyecto
- **Tecnología Principal**: HTML
- **Estilos**: Tailwind CSS (Versión 4.*)
- **Gestor de Paquetes**: npm / Node.js

## Estructura del Proyecto
```text
input/
 └─ input.css
src/
 ├─ assets/
 │   ├─ css/
 │   │   └─ style.css (Generado por Tailwind)
 │   ├─ image/
 │   └─ js/
 └─ index.html
```
